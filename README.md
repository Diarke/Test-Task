# Отчёт по договорам

Нужен Python 3.9+, больше ничего ставить не надо.

```
python3 report.py --date 10.11.2026
python3 report.py --date 10.11.2026 --csv-dir out   # плюс CSV для таблицы
python3 -m unittest -v                              # проверки
```

Дата: `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`. Данные берутся из `data/` (другая папка: `--data путь`).
Отчёт на любую дату считается по истории дат в данных, а не по статусам на момент выгрузки.
Решения и допущения - в `DECISIONS.md`, записка бухгалтеру - в `NOTE_FOR_ACCOUNTANT.md`.
